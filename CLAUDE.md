# Artist Intelligence Platform — Claude Code Instructions

## Project Overview
This is a full-stack artist intelligence platform for a Roc Nation distributed artist with low exposure. The goal is to build a complete system across 5 sessions.

## Tech Stack
- **Frontend**: Next.js 14 (App Router) + Tailwind CSS
- **Backend**: Node.js + Express APIs  
- **Database**: PostgreSQL (via Prisma ORM)
- **Hosting**: Railway (primary)
- **AI**: Anthropic Claude API (content generation)

## Session Roadmap

### Session 1 — Foundation
- Dynamic song catalog (one template, all songs from DB)
- Fan capture system (email/phone for exclusive content)
- SEO-optimized song pages (Claude-generated descriptions)
- Railway deployment + custom domain

### Session 2 — Data Connections
- Spotify API (streaming data by city, listener demographics)
- YouTube API (view counts, audience locations)
- Instagram API (engagement by location)
- TikTok API (reach/engagement data)

### Session 3 — Geofencing
- Location capture on every site visit
- Merch purchase location mapping
- Live event geofencing
- Real-time fan map

### Session 4 — Automation
- Content repurposing bot (YouTube → TikTok/Reels/Twitter)
- Playlist submission automation (Spotify curators)
- Press outreach bot (hip hop blogs + publications)

### Session 5 — Intelligence Dashboard
- Private dashboard (artist/manager only)
- Fan location heatmap
- Streaming analytics by city
- Ad spend optimization insights
